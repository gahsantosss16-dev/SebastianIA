# Roadmap do Sebastian IA

## Visão geral

O Sebastian IA é um assistente pessoal inteligente, modular e orientado por princípios de segurança, transparência e evolução contínua.

## Fases

### Fase 1 — Fundação
- Estabelecer a base arquitetural do projeto.
- Definir o core, configuração, logging e infraestrutura inicial.
- Preparar o projeto para crescer de forma organizada.

### Fase 2 — Expansão
- Introduzir módulos adicionais de forma incremental.
- Integrar novos componentes conforme a arquitetura definida.

## SPECs concluídas

- SPEC-001 — Estrutura inicial do projeto e base de documentação.
- SPEC-002 — Infraestrutura do core.
- SPEC-003 — Event Bus interno.
- SPEC-004 — Service Container interno.
- SPEC-005 — Lifecycle Manager interno.
- SPEC-006 — Plugin Manager interno.
- SPEC-007 — Error Handling centralizado.
- SPEC-008 — Health Monitor centralizado.
- SPEC-009 — Configuration Manager centralizado.

## SPECs planejadas

- Evolução do core com novos módulos.
- Integração de memória e agentes.
- Expansão da camada de interfaces e automações.

## Status das fases

- Fase 1: Em andamento.
- Fase 2: Planejada.
