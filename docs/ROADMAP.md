# Roadmap do Sebastian IA

## Visão geral

O Sebastian IA é um assistente pessoal inteligente, modular e orientado por princípios de segurança, transparência e evolução contínua.

## Fases

### Fase 1 — Core Foundation
- Estabelecer a base arquitetural do projeto.
- Definir o core, configuração, logging e infraestrutura inicial.
- Preparar o projeto para crescer de forma organizada.

### Fase 2 — Expansão
- Introduzir módulos adicionais de forma incremental.
- Integrar novos componentes conforme a arquitetura definida.
