# Sebastian IA

> Um assistente pessoal inteligente, desenvolvido por Gabriel dos Santos Bezerra.

## Visão

O Sebastian IA é um assistente pessoal criado para auxiliar no trabalho, nos projetos e nas tarefas do dia a dia.

Seu objetivo não é apenas responder perguntas, mas compreender contexto, manter memória, utilizar ferramentas, executar tarefas autorizadas e evoluir continuamente ao lado do usuário.

O projeto foi concebido para se tornar um verdadeiro parceiro digital, inspirado na ideia de um "Jarvis", porém totalmente personalizado para a forma de trabalho de Gabriel.

## Objetivos

- Possuir memória própria e permanente.
- Auxiliar no desenvolvimento de software.
- Integrar projetos, documentos e bancos de dados.
- Executar tarefas mediante autorização.
- Aprender continuamente com o histórico do usuário.
- Priorizar segurança, transparência e confiabilidade.

## Princípios

- Nunca ocultar erros.
- Diferenciar fatos de hipóteses.
- Solicitar confirmação antes de ações críticas.
- Registrar ações importantes.
- Evoluir de forma organizada e documentada.
